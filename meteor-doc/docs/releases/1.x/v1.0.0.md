# v1.0.0 (2016-10-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>1.0.0</version>
</dependency>
```

## 新增

- 首次发布 RSF，支持服务发布、订阅、动态撤销，以及服务分组和版本。
- 支持同步、异步、回调、泛化调用、单向消息和隐式传参。
- 支持固定地址和注册中心发现，缓存提供者地址并暂时隔离失效地址。
- 支持按服务、方法、参数分流，以及请求限流和同机房优先。
- 提供 Telnet 管理、服务上下线、调用拦截器和序列化扩展。
