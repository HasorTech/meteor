# v4.1.5 (2020-05-09)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>4.1.5</version>
</dependency>
```

## 优化

- Hprose 和 Hessian 改用官方依赖，替换仓库内保存的第三方源码。
- 打包时将 Hprose `2.0.38`、Hessian `4.0.63` 放入 RSF 独立包名，减少与应用依赖的类名冲突。

## 不兼容更新

- 内置 Hprose、Hessian 类的包名由 `net.hasor.rsf.libs.*` 调整为 `net.hasor.rsf.hprose`、`net.hasor.rsf.hessian`。
