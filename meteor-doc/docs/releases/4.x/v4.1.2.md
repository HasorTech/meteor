# v4.1.2 (2020-03-04)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>4.1.2</version>
</dependency>
```

## 优化

- 规则解析失败时输出具体错误消息和异常堆栈。

## 不兼容更新

- RSF 默认关闭，使用时需设置 `hasor.rsfConfig.enable=true`。
- 自定义流控规则的 `paserControl()` 更名为 `parseControl()`。
