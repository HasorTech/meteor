# v4.1.0 (2020-02-03)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>4.1.0</version>
</dependency>
```

## 优化

- Telnet 管理改用独立的 tConsole 模块。
- 支持使用域名配置提供者地址，并完善域名地址的刷新。

## 修复

- 修复连接器绑定地址和入站标记处理，以及动态 IP 环境下的连接限制。

## 不兼容更新

- 服务和过滤器的对象创建接口改用 Java `Supplier`。
- 默认配置文件改为 `hconfig.properties`；数据目录改用 `RSF_DATA_HOME` 配置。
