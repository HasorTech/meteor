# 治理能力

按业务需要选择治理方式，脚本通过[控制台](../../console/web.md)、[Telnet](../telnet/rule.md)或 [API](../api.md)配置。

## 使用指引

- [按 IP 分流](../routing.md)，只调用指定 IP，或排除某个实例。
- [按方法分流](../method-routing.md)，让指定方法调用独立实例。
- [按参数分流](../args-routing.md)，按租户编号等参数选择实例。
- [本地优先](../local.md)，优先调用同一应用上下文中的服务实现。
- [同机房优先](../units.md)，优先调用同机房实例，必要时跨机房调用。
- [请求限流](../limits.md)，限制单个消费者的请求发送速率。
- [服务停用](../enabled.md)，停用服务或阻断实例。
- [元信息](../metadata.md)，维护负责人、环境等服务属性。

自定义脚本的变量、条件和返回值见[规则语法](../rule-syntax.md)。

## 执行顺序

**同机房优先 → 按 IP 分流 → 按方法分流 → 按参数分流 → 随机选择实例 → 请求限流。**

分流规则依次筛选地址，后面的规则不能恢复前面已排除的地址。临时指定 IP 和端口调用时，直接使用该地址。
