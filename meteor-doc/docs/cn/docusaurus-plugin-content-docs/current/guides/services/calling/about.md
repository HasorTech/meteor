# 调用方式

服务订阅完成后，可按业务是否需要等待结果、如何接收结果来选择调用方式。

## 使用指引

- [同步调用](../invocation.md)，通过服务接口调用，等待并取得结果。
- [泛化调用](../dynamic.md)，通过方法名、参数类型和参数值发起调用。
- [异步调用](../async.md)，提交请求后继续处理其他工作，再读取结果。
- [回调调用](../callbacks.md)，通过成功、失败回调接收结果。
- [流式调用](../streaming.md)，在一次调用中逐条发送或接收消息。
- [单向消息](../messages.md)，发送无需业务返回值的通知。
- [隐式传参](../options.md)，不修改方法签名，传递请求编号等信息。
