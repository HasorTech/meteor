# 开发手册

Meteor 通过接口定义服务，由提供者发布、消费者订阅，支持同步、异步等调用方式。项目接入见[创建应用](../application/overview.md)。

## 使用指引

- [定义服务](contracts.md)，声明服务接口，指定服务的分组、名称和版本。
- [发布服务](publish.md)，将业务实现注册为服务，供消费者调用。
- [订阅服务](consume.md)，登记要调用的接口，通过直连、地址本或注册中心获取提供者地址。
- [同步调用](invocation.md)，调用服务接口，等待并取得结果。
- [泛化调用](dynamic.md)，通过方法名、参数类型和参数值发起调用。
- [异步调用](async.md)，提交请求后继续处理其他工作，再读取结果。
- [回调调用](callbacks.md)，通过成功、失败回调接收调用结果。
- [流式调用](streaming.md)，在一次调用中逐条发送或接收消息。
- [单向消息](messages.md)，发送无需业务返回值的通知。
- [隐式传参](options.md)，不修改方法签名，传递请求编号等信息。
- [服务发现](../discovery/about.md)，通过直连、地址本或注册中心获取提供者地址。
- [多协议发布](multiple/about.md)，让同一服务支持多种协议，设置端口和访问路径。
- [生命周期](lifecycle/about.md)，控制应用上下线、监听状态变化，并注册调用拦截器。
- [框架配置](configuration/about.md)，配置超时、网络、线程并发、地址缓存和数据目录。
- [安全通信](security/about.md)，配置连接加密、证书校验和管理认证。
