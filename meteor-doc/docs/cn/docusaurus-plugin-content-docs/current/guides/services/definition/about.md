# 发布订阅

接口定义可调用的方法，分组、名称和版本确定服务。提供者注册实现对象，消费者登记要调用的接口。

## 使用指引

- [定义服务](../contracts.md)，声明接口，设置服务的分组、名称和版本。
- [发布服务](../publish.md)，注册实现对象，供消费者调用。
- [订阅服务](../consume.md)，登记要调用的接口。

## 补充说明

应用启动方式见[创建应用](../../application/overview.md)，提供者地址来源见[使用固定地址](../../discovery/direct.md)、[使用地址本](../../discovery/address-book.md)、[服务发现](../../discovery/zookeeper.md)。
