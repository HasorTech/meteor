# v3.2.2 (2018-01-02)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>3.2.2</version>
</dependency>
```

## 新增

- 增加 HTTP 传输和 Hprose HTTP 调用支持。
- 增加 `InstanceInfo`，可查询实例的默认协议和连接器信息。

## 优化

- 恢复 RSF 连接握手；默认协议启动失败时终止应用启动。

## 修复

- 修复多协议配置、基础类型解码，以及连接关闭时的异常处理。
