# v3.2.0 (2017-10-15)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>3.2.0</version>
</dependency>
```

## 优化

- RSF 纳入 Hasor 的统一版本发布，版本号调整为 `3.2.0`。
- Spring 整合从 RSF 内核分离，由独立插件提供。

## 不兼容更新

- 运行环境要求 Java 8 或以上版本。
