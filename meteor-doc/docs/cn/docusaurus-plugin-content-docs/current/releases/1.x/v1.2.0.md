# v1.2.0 (2017-01-29)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>1.2.0</version>
</dependency>
```

## 新增

- 支持多协议发布，增加 Hprose 协议，允许其他语言的 Hprose 客户端调用。
- 开放 RPC 协议扩展，可接入自定义协议。
- 支持 Spring 4.x 和 Spring Boot 整合。

## 不兼容更新

- `RsfApiBinder` 改用 Hasor 扩展机制，接入时不再要求使用 `RsfModule`；移除 `RsfPlugin`。
- 取消 RSF 握手，以及双向请求共享连接的机制；保留同一请求方向的连接复用。
- `RsfCenterEvent` 从枚举改为字符串事件名。
