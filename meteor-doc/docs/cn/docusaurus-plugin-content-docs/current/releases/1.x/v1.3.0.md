# v1.3.0 (2017-02-17)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>1.3.0</version>
</dependency>
```

## 优化

- 分离 RPC 内核和注册中心，提供者、消费者不再引入整个注册中心工程。
- 远端异常响应携带异常类型和消息，便于定位业务错误。

## 修复

- 修复无参方法调用的空指针异常。
- 修复 Hprose 基础类型解码，以及消费端接收到其他协议地址的问题。
- 明确拒绝尚不支持的 Hprose 批量调用和引用参数。
