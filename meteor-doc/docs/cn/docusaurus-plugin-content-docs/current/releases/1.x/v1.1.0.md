# v1.1.0 (2016-12-01)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>1.1.0</version>
</dependency>
```

## 新增

- `RsfApiBinder.converToProvider()` 支持将 RSF 服务交给 Hasor 注入。
- `RsfPublisher` 可从 `AppContext` 获取；`RsfUpdater` 可查询提供者地址。
- 增加 Telnet `info` 和 `detail` 命令，分别查看应用配置和服务详情。
- 增加 `RSF_GATEWAY_IP`、`RSF_GATEWAY_PORT`，支持通过端口映射公布外部访问地址。

## 优化

- 简化注册中心客户端；Telnet `list` 只列服务名称，详情由 `detail` 查看。

## 修复

- 修复 Spring 整合中用户设置的服务分组、名称和版本被默认值覆盖的问题。
- 修复 Tomcat 中地址缓存线程的类加载器使用错误。
