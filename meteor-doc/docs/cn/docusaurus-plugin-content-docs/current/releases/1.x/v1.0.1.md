# v1.0.1 (2016-11-08)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-rsf</artifactId>
    <version>1.0.1</version>
</dependency>
```

## 新增

- 增加 Spring 整合，可在 Spring 中配置和注入 RSF 服务。

## 修复

- 修复关闭服务时的类加载异常。
- 修复服务绑定时提供者和消费者的识别问题。
