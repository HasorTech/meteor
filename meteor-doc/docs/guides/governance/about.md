# 服务治理

通过控制台、Telnet 或 API 管理服务状态、路由、限流和元信息。治理脚本相同，选择适合的操作入口即可。

## 操作入口

- [使用 API](api.md)：在程序中修改当前应用，或通过注册中心保存配置。
- [使用控制台](../console/about.md)：在网页中查看应用和服务、调试方法、编辑治理配置。
- [使用 Telnet](telnet/about.md)：连接应用的管理端口，查询当前实例并执行治理命令。

## 生效范围

本地 API 只修改当前应用的运行状态。Telnet 未接入注册中心时也在本地生效，重启后按启动配置恢复。

控制台通过注册中心保存配置。Telnet 已接入注册中心时，将修改保存到当前实例或实例下的服务；注册中心 API 还可操作整个服务和集群默认配置。注册中心保存的配置需要应用同步后生效。
