# 介绍

<!-- llms:start -->

Meteor 是面向 Java 的多协议 RPC 框架。它把 Java 业务接口发布为远程服务，让同一份业务实现支持多种 RPC 协议；Java 应用也可以通过 Meteor 调用其他系统的 RPC 服务。

## 能解决什么问题

- **服务需要对接不同客户端**：为同一份业务开放多个协议，供 Java、Python、Go、JavaScript、C/C++ 等客户端调用，语言支持范围取决于所选协议。
- **已有系统采用不同 RPC 框架**：通过相应协议接入现有服务，在 Java 代码中使用接口发起调用。
- **服务运行在多个实例上**：通过注册中心发现地址，配置分流和限流规则，并通过控制台查看服务、调试方法。

## 如何接入

Meteor 嵌入用户应用运行，业务代码负责实现接口，Meteor 负责网络通信和远程调用。普通 Java 项目可以直接使用，也可以通过 Spring、Hasor、Solon 整合，让框架管理服务发布和接口注入。

协议、注册中心、Web 控制台和 Telnet 按需引入。使用固定地址即可开始调用，也可以随后接入注册发现和服务治理。
